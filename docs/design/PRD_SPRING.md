# PRD: Musim Spring (Garden Life - First Release)

## 1. Objektif
- Musim 30 hari in-game (180 jam real-time).
- Pengenalan mekanik cuaca, air, dan perlindungan tanaman.

## 2. Mekanik Utama
- **Sistem Rarity:** 6 tier (Common hingga Mystic) + Transcendent.
- **Toko Spring:** Terbatas pada tier Common, Uncommon, dan Rare.
- **Cuaca:** Roster Sunny (40 tick), Cloudy, Windy, Heatwave, Summer Shower, Muggy, Tornado (endpoint rantai).
- **Perlindungan:** Storm Catcher (2/plot), Storm Shield (1/plot, 3 level).

## 3. Ekonomi
- Harga Beli Benih: Common(100) s/d Mystic(250k).
- Season Pill: 80% harga jual buah dewasa.

## 4. Acceptance Criteria
- Transisi 3 hari berjalan.
- Tanaman tidak cocok dengan musim aktif dapat masuk status Rest sesuai aturan musim; label UI tidak memakai Dormant.
- Rantai Tornado berfungsi sesuai aturan rantai.
- Uprooted/Windblown fungsional dengan Trowel.
